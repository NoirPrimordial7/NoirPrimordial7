# NOIR — Ink & Curiosity

## Identity
Aditya Gholap / NoirPrimordial7. Software developer and B.Tech CSE student specializing in Cloud Computing, based in Pune.

A face-free N7 emblem takes the sharp elegance and black/red/gold mood of Diablo / Noir as inspiration. It is an abstract personal monogram, not a character portrait. The hooked flourish, angular cuts and ink texture carry the personality. The latest user correction explicitly excludes faces, so neither rejected portrait is included in this repository.

## Art direction
Urban doodle and comic ink, with warm eccentric Frasurbane-inspired serif typography. The supplied videos informed print texture, playful drawn symbols, layered composition, rhythmic motion, and the burgundy/ochre atmosphere. Their footage is not reused. The N7 logo and cover were created with the built-in image-generation tool; exact prompts are in `design/prompts/`. Project logos and motion graphics are original code-native artwork.

Research reference for the Frasurbane component: https://cari.institute/aesthetics/frasurbane. Character mood reference: https://tensura.fandom.com/wiki/Diablo. These inform the art direction, not factual profile claims.

## Typography and drawing
The cover uses generated expressive serif lettering. Editable project plates use Georgia with system serif fallbacks. Small labels use monospace. Actual profile information stays in GitHub's native text for accessibility and mobile readability. Hand-drawn arrows, tilted paper stamps, four-point ink sparkles, and halftone corners connect the system.

## Marks
- NearNest: neighborhood house inside a location pin.
- Market Navigator: compass plus ascending chart path.
- Wildlife Recognition: paw inside an observation frame.

All four project marks are original SVGs and can be edited in `scripts/build_noir_v2.py`. These are proposed project identities, not claims about existing official branding.

## Usage
`assets/identity/noir-avatar.jpg` is the opaque upload-ready profile photo (about 203 KB). `noir-avatar.png` is the high-resolution master; `noir-n7-emblem.png` is transparent. Use the black transparent emblem on a light background. Keep generous clear space and do not add a face to it.

`preview/identity.html` provides a circular-crop preview, small-size examples, the palette, and logo downloads. `preview/index.html` shows the README. These local review pages are ignored by Git. Neither the avatar nor the README has been published.
