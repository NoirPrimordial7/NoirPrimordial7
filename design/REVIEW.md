## Rebuild and review
Install `scripts/requirements.txt`, then run `python scripts/build_noir_v2.py` and `python scripts/validate_assets.py`. The motion strip uses Windows Georgia and Consolas fonts. Code-native SVGs use system fallbacks. Raster illustration masters are not regenerated by the script; exact generation prompts are saved separately.

Open `preview/index.html` for the README and `preview/identity.html` for the identity kit, or serve the repository locally and visit `/preview/`. Preview HTML and QA captures are Git-ignored. No JavaScript or custom CSS is required in the README itself.
