# AI-Powered Market Navigator

**01 / ML prototype**

Explores stock-price trends with an LSTM model, technical indicators, and Reddit/news sentiment in an interactive Streamlit workflow.

## Inside the system

Historical market data is prepared with MinMax scaling and indicators including RSI, SMA, MACD, and Bollinger Bands. TensorFlow/Keras inference and VADER sentiment bring numerical and text signals into the same workflow.

**Built with:** Python · TensorFlow / Keras · LSTM · Streamlit

## Current scope

A forecasting experiment. Published benchmark results and forecast accuracy are not claimed here; external data and sentiment integrations need configuration.
