# CASE / 03 — Kumbh Kavach

Explores family safety in crowded places through a working PWA with a regional map, reunion flow and simulated separation/SOS scenarios.

## Inside the system

The jury demo works without accounts or hardware. Family movement, bands and SOS scenarios are simulated; browser geolocation is optional. This is a demonstrator, not a deployed emergency service or an offline mesh network.

**Components:** React · TypeScript · MapLibre · Zustand
